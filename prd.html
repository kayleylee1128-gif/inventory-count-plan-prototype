盘点计划模块需求文档

基于拣货异常、动销、抽盘、周期性盘点及历史差异，自动或手动生成 SKU + 货位维度的盘点任务。

评审状态：原型已确认适用角色：仓库主管 / 库存管理员更新日期：2026-08-17

1. 背景与目标

仓库日常盘点依赖人工经验或固定周期，难以及时覆盖缺货、高动销和历史差异数据，也容易重复创建同一 SKU + 货位任务。盘点计划模块将风险识别、任务拆分、去重和执行调度统一管理。

险

主动识别风险

根据作业异常、动销和盘点结果筛选高风险数据。

自

自动生成任务

支持每天、每周、每月 X 号以及事件触发执行。

控

避免重复盘点

剔除近期已盘点及待执行、执行中的重复明细。

范围边界

范围内范围外
计划新增、编辑、启停、查询盘点任务领取及人员分配
策略条件、去重规则、任务拆分实盘录入、复核和差异审批
定时及手动执行、生成记录库存差异账务调整与经营分析

2. 业务流程

配置计划仓库、策略、周期
计算候选执行时实时计算
去重排除近期已盘与在途任务
拆分任务按明细上限拆分
记录结果命中、剔除、任务数
统一数据粒度　所有策略最终均生成 SKU + 货位明细。同一 SKU 位于多个货位时，按多个候选明细处理。

3. 页面与信息架构

区域需求
顶部概览仅展示启用计划数、今日已生成任务数；不展示待执行任务及近 7 天重复剔除统计。
查询区按计划名称、计划类型、适用仓库、状态筛选。
计划列表展示策略、条件、任务规则、周期、状态、下次执行时间及操作。
新建/编辑抽屉基础信息 → 盘点策略 → 筛选条件 → 任务规则 → 执行计划。
生成记录展示执行方式、命中数、剔除数、任务数、执行结果和时间。

4. 五类盘点策略

缺

拣货异常

过去 X 天发生拣货缺货且次数达到阈值。

销

动销

按销售状态、出库数量和统计时间筛选。

抽

抽盘

从已完成盘点结果中随机抽取 SKU。

周

周期性盘点

按指定通道和货位状态周期覆盖。

差

历史差异

复盘差异率较高或连续发生差异的数据。

4.1 拣货异常

固定事件为“拣货缺货”，页面不展示统计事件字段。

数据来源　取进入“拣货缺货”模块的数据，按 SKU + 货位维度生成候选明细。
字段控件默认值规则
发生时间数字输入 + 天7正整数，统计过去 X 天
缺货次数数字输入 + 次1正整数，大于等于 X 次

4.2 动销

数据来源　取计划对应仓库在统计周期内的实际出库件数，按 SKU 汇总后关联当前货位。
字段控件默认值规则
销售状态下拉单选在售在售停售清仓
出库数量数字输入 + 件100正整数，大于等于
统计时间数字输入 + 天30正整数，过去 X 天

4.3 抽盘

数据来源　取状态为“已完成”的历史盘点数据，并根据盘点结果和完成时间形成抽样数据池。
字段控件默认值规则
盘点完成时间数字输入 + 天30只统计已完成盘点
盘点结果下拉多选盘平、盘盈、盘亏标签回显，可逐项移除；不分别配置抽样比例
随机抽取数量数字输入 + 个 SKU100从全部符合条件的数据中等概率随机抽取

4.4 周期性盘点

不展示额外“范围类型”字段。

数据来源　取用户指定通道对应的货位，并按货位状态过滤后生成盘点明细。
字段控件默认值规则
指定通道下拉多选A01、A02标签回显，可逐项移除，至少选择一个通道
货位状态下拉单选启用启用停用全部

4.5 历史差异

数据来源　取状态为“已完成”的历史盘点数据，根据最终盘点结果计算差异率和连续差异次数。
字段控件默认值规则
盘点差异率数字输入 + %2支持小数，大于等于且必须大于 0
连续差异次数数字输入 + 次2正整数，大于等于
统计时间数字输入 + 天30正整数，过去 X 天

5. 通用规则

5.1 去重与排除

规则默认处理方式
剔除过去 X 天已完成盘点的 SKU + 货位开启，X=3按已完成时间判断，同一明细不再进入候选集
剔除已有待执行/执行中任务的数据开启防止同一 SKU + 货位并发生成
排除零库存货位关闭开启后执行时库存为 0 的货位不进入任务

5.2 任务拆分

字段默认值规则
每任务明细上限50 条按去重后的 SKU + 货位明细行数计算；超过上限自动拆分
单次生成上限1,000 条超出部分留待下次执行
拆分方式仓库 + 库区可支持按仓库、库区或通道拆分

5.3 执行计划

模式配置说明
每天执行时间例如每天 02:00
每周星期 + 时间例如每周一 03:00
每月每月 X 号 + 时间目标日期在当月不存在时，提前至当月最后一天执行
仅手动执行无不自动触发，可在列表立即执行
条件触发后立即执行触发条件事件命中后立即计算并生成任务

6. 盘点指令需求

6.1 执行逻辑调整

取消多轮盘点　执行盘点指令时，去掉“复盘”和“终盘”逻辑。每张盘点指令只执行一次盘点并形成最终结果，不再因差异自动生成复盘单或终盘单。
项目调整后规则
盘点轮次仅保留一次盘点，不区分初盘、复盘和终盘。
差异处理完成后直接记录盘平、盘盈或盘亏；后续差异处理由独立业务流程承接。
历史数据历史复盘、终盘单据保留原类型展示；新生成指令不再产生这两类单据。
状态流转待领取 → 盘点中 → 已完成；异常时进入已取消或执行失败。

6.2 盘点指令页面

调整项需求说明
筛选条件“盘点类型”调整为：日常盘点拣货缺货动销抽盘周期性历史差异。默认“全部”，支持单选筛选。
列表“盘点类型”展示当前指令所属业务类型，与筛选枚举一致；原手工创建的常规盘点归为“日常盘点”。
列表新增“来源单号”展示生成盘点指令的来源业务单号，并支持点击查看来源。盘点计划生成的指令展示计划编号；拣货缺货展示缺货单号；日常盘点无来源单时显示“—”。
来源追溯来源单号随盘点指令快照保存，来源业务单后续变更或删除不影响历史指令展示。

6.3 盘点差异与占用订单处理

触发条件　货位存在订单占用，且盘点后的实盘数量小于该货位的占用数量。系统需释放超出实盘数量的订单占用，避免库存被超额分配。
计算占用缺口占用数量 - 实盘数量
选择占用订单按订单创建时间倒序
剔除拣货任务释放货位库存占用
校验其他货位判断可用库存是否足够
更新订单状态待生成或仓库退回
步骤处理规则
1. 计算需释放数量需释放数量 = 当前货位占用数量 - 盘点后实盘数量。仅当结果大于 0 时执行后续处理。
2. 选择订单查询占用该货位、尚未完成拣货的订单，按照订单创建时间倒序处理，即优先释放创建时间较晚的订单。若创建时间相同，按订单号倒序作为稳定排序。
3. 释放占用依次将订单从当前拣货任务中剔除并释放其货位占用，直到累计释放数量大于等于需释放数量。已完成或已出库的订单不得回退。
4. 校验其他货位按仓库 + SKU 维度，校验除当前盘点货位外的其他可用货位库存；可用库存需扣除其他订单已占用量、冻结量及不可销售库存。
5A. 库存充足若其他货位的可用库存足以满足订单待分配数量，则订单重新回到“待生成”状态，等待系统重新生成拣货任务并分配新货位。
5B. 库存不足若其他货位可用库存不足，则取消该订单在仓库系统中的拣货任务和库存占用，并将订单从仓库系统退回上游系统；记录退回原因“盘点差异导致库存不足”。
事务与并发　盘点结果落账、订单占用释放和状态变更应在同一事务或可补偿流程内执行。处理期间锁定仓库 + SKU 库存分配，使用盘点指令 ID + 订单号作为幂等键，防止重复剔除或重复退回。

7. 交互与状态

场景触发反馈
策略切换点击策略卡片重绘对应条件，通用字段保持不变
数字非法空值、0 或负数字段错误态，保存时提示并阻断
多选为空移除全部结果或通道显示占位提示，保存时阻断
规则预览条件或任务上限变化实时更新自然语言规则和拆分结果
立即执行点击并二次确认重新计算候选数据，反馈生成结果
执行失败数据源或系统异常不生成部分任务，记录原因并支持重试

8. 数据与接口口径

候选唯一键：warehouse_id + sku_id + location_id
时间窗口按仓库时区计算，边界由接口统一定义
盘点结果取已完成盘点任务的最终结果
差异率：|实盘数-账面数| ÷ max(|账面数|,1)
任务生成必须具备执行批次幂等键
生成记录保存计划快照和各阶段统计数

9. 权限、日志与非功能要求

类别要求
权限仓库主管可新建、编辑、启停和立即执行；库存管理员按授权操作。
日志记录新增、编辑、启停、手动执行及关键字段变更前后值。
性能候选计算建议 60 秒内完成，超时转异步并展示处理中。
一致性任务生成和生成记录在同一事务或可补偿流程中完成。
可观测性记录计划 ID、执行批次 ID、各过滤阶段数量和失败信息。

10. 验收标准

拣货异常不展示统计事件，两项条件均为数字输入
动销使用销售状态单选和两个数字输入
抽盘结果支持多选，随机数量为数字输入
周期性盘点通道多选、货位状态单选
历史差异三个配置值均为数字输入
支持每天、每周、每月 X 号和手动执行
执行时正确剔除已盘点及执行中重复数据
任务按去重后的 SKU + 货位行数及明细上限拆分，并生成完整记录
非法值和空多选均阻断保存并明确提示
原型标注筛选、计数和双向定位正确
新盘点指令不再生成复盘或终盘单据
盘点类型筛选包含六类新枚举且列表展示一致
列表展示来源单号并可追溯来源业务
实盘数小于占用数时按订单创建时间倒序释放占用
其他货位库存充足时订单回到待生成状态
其他货位库存不足时订单从仓库系统退回并记录原因
